# Test Plan: Expense Tracker v1.0

## 1. Цель тестирования
Проверить функционал добавления расходов и расчёта итоговой суммы перед релизом.

## 2. Объект тестирования
Веб-приложение "Трекер личных расходов" (Flask + HTML).

## 3. Scope (Объём тестирования)
**Входит в скоуп:**
- Форма добавления расхода (валидация полей)
- Расчёт итоговой суммы за текущий месяц
- Отображение главной страницы

**Не входит в скоуп:**
- Авторизация пользователей (её пока нет)
- База данных (используется in-memory хранилище)
- Производительность (нет нагрузки)

## 4. Подход к тестированию
- Ручное функциональное тестирование
- Негативное тестирование (валидация полей)
- Тестирование граничных значений (0, отрицательные, спецсимволы)

## 5. Окружение
- Windows 10/11
- Chrome (последняя версия)
- Python 3.x + Flask 2.3.2

## 6. Критерии начала/окончания тестирования
**Начало:** развёрнутое локальное приложение.
**Окончание:** все Critical и Major баги заведены в Issues, смоук-тесты проходят.

## 7. Риски
- Отсутствие авторизации → данные может испортить любой пользователь
- Хранение данных в памяти → при перезапуске сервера все расходы теряются
