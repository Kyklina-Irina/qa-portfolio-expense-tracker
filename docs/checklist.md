# Чек-лист тестирования формы добавления расхода

| № | Что проверяем | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Добавить валидный расход (Еда, 100, сегодня) | Расход добавлен, сумма обновилась | ⬜ |
| 2 | Оставить все поля пустыми | Ошибка валидации, расход не создан | 🐞 Bug |
| 3 | Сумма = 0 | Ошибка валидации | 🐞 Bug |
| 4 | Сумма = -100 | Ошибка валидации | 🐞 Bug |
| 5 | Сумма = "100abc" | Уточнить у аналитика (❓) | ⬜ |
| 6 | Дата из будущего | Ошибка валидации | 🐞 Bug |
| 7 | Дата из прошлого месяца | Расход создан, НЕ попадает в "Итого за текущий месяц" | 🐞 Bug |
| 8 | Категория вне списка | Ошибка валидации | 🐞 Bug |
| 9 | Сумма = "." (точка) | Ошибка валидации, сервер НЕ падает | 🐞 Bug (Critical) |
| 10 | Добавить несколько валидных расходов за текущий месяц | Сумма корректно суммируется | ⬜ |
